# Курсовой проект: База данных "Онлайн-курсы"

Файловая база данных – это файл, в котором хранятся упорядоченные записи данных, описывающих заданную предметную область. Для работы с ними необходимо реализовать программу, позволяющую создавать новые записи, выполнять поиск по заданным критериям.

Целью данной работы является разработка программы для реализации файловой базы данных с заданным набором функций.

Для достижения поставленной цели, необходимо решить следующие задачи:

1. Реализовать структуру данных и определить подходящие типы данных для каждого поля.

2. Реализовать простой и понятный интерфейс для взаимодействия пользователя с программой, который будет работать пока пользователь не захочет выйти из программы.

3. Реализовать сохранение данных в бинарный файл и загрузку данных из бинарного файла.

4. Реализовать поиск записей по названию курса (по полному названию или его части).

5. Реализовать сортировку записей по рейтингу курса.

## Поля структуры course

1. `char name[50]` - название курса

2. `char teacher[50]` - преподаватель

3. `char topic[50]` - тема курса

4. `float rating` - рейтинг курса (от 0 до 5)

5. `double cost` - стоимость курса

6. `int duration` - длительность курса (в часах)

## Выполняемые программой операции

1. Загрузка данных из файла – загрузка базы данных курсов из бинарного файла, имя которого вводит пользователь.
2. Просмотр всех записей – вывод всей базы данных курсов на экран.
3. Поиск по названию курса – поиск курсов, в названии которых содержится введённая строка (поиск чувствителен к регистру).
4. Сортировка данных – сортировка всей базы данных по рейтингу курса по возрастанию.
5. Добавление новой записи – ввод информации о новом курсе с клавиатуры.
6. Сохранение данных в файл – сохранение имеющихся данных в бинарный файл, имя которого вводит пользователь.
7. Заполнение случайными данными – добавление записей со случайными значениями.
8. Выход – завершение работы программы.

## Описание функций программы

1. `int show_menu()`

   Назначение: Отображает текстовое меню с доступными действиями и получает выбор пользователя.

   Возвращает: Целое число (int), соответствующее выбранному пункту меню (от 1 до 8).

2. `void read_line(const char* prompt, char* buffer, int size)`

   Назначение: Выводит приглашение и считывает с клавиатуры строку с пробелами, не допуская выхода за границы массива. После чтения очищает буфер ввода.

   Параметры:

   - prompt - текст приглашения к вводу.
   - buffer - массив, в который записывается введённая строка.
   - size - размер массива buffer.

3. `course input_data()`

   Назначение: Интерактивно запрашивает у пользователя данные для заполнения одной записи.

   Возвращает: Заполненную структуру course с данными, введёнными пользователем.

4. `void output_data(course c)`

   Назначение: Выводит на экран все поля записи.

   Параметры:

   - c - структура course, данные которой нужно отобразить.

5. `int load_from_file(const char* filename, course* courses)`

   Назначение: Загружает массив записей из бинарного файла в память (не более MAX записей).

   Параметры:

   - filename - имя файла.
   - courses - указатель на массив структур course.

   Возвращает: количество успешно загруженных записей или -1, если файл не удалось открыть.

6. `void view_all_records(course* courses, int count)`

   Назначение: Отображает все записи, находящиеся в оперативной памяти.

   Параметры:

   - courses - указатель на массив структур course.
   - count - количество актуальных записей в массиве.

7. `int search_by_name(const course* courses, int count, const char* query, int* found_indexes)`

   Назначение: Осуществляет поиск записей, название которых содержит заданную подстроку (используется `strstr`).

   Параметры:

   - courses - указатель на массив структур course.
   - count - количество записей в массиве.
   - query - искомая подстрока.
   - found_indexes - массив для индексов найденных записей.

   Возвращает: количество найденных записей или -1 в случае некорректных параметров.

8. `int compare(const void* a, const void* b)`

   Назначение: Функция сравнения для `qsort`. Сравнивает две записи по рейтингу курса (по возрастанию).

   Параметры:

   - a, b - указатели `const void*` на сравниваемые элементы массива.

9. `void sort_data(course* courses, int count)`

   Назначение: Сортирует массив записей по возрастанию рейтинга, используя стандартную функцию `qsort` и функцию сравнения `compare`.

   Параметры:

   - courses - указатель на массив структур course.
   - count - количество актуальных записей в массиве.

10. `int add_new_record(course* courses, int count)`

    Назначение: Добавляет одну новую запись в массив. Данные для записи запрашиваются у пользователя через функцию `input_data`. Если достигнут лимит MAX (100), запись не добавляется.

    Параметры:

    - courses - указатель на массив структур course.
    - count - текущее количество актуальных записей в массиве.

    Возвращает: новое количество записей в массиве после добавления.

11. `int save_to_file(const char* filename, const course* courses, int count)`

    Назначение: Сохраняет все текущие записи из оперативной памяти в бинарный файл.

    Параметры:

    - filename - имя файла.
    - courses - указатель на массив структур course.
    - count - количество записей, которые необходимо сохранить.

    Возвращает: количество сохранённых записей или -1, если файл не удалось создать.

12. `int getRandomNumber(int min, int maxxx)`

    Назначение: Возвращает случайное целое число из диапазона [min, maxxx].

13. `int generate_random_data(course* courses, int count)`

    Назначение: Генерирует указанное пользователем количество записей со случайными данными (название, преподаватель и тема выбираются из заготовленных списков; рейтинг – от 0.0 до 5.0, стоимость – от 500 до 10000, длительность – от 5 до 120 часов) и добавляет их в массив.

    Параметры:

    - courses - указатель на массив структур course.
    - count - текущее количество актуальных записей в массиве.

    Возвращает: новое количество записей в массиве после добавления сгенерированных.
